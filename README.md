# Portfolio_Bogolyubova
Одностраничный сайт-визитка для веб-дизайнера. Сверху — полноэкранный хедер с крупным именем и прозрачной навигацией поверх тёмного фона. Дальше по порядку: блок «Обо мне» с фото и коротким описанием, слайдер услуг (буклеты, плакаты, веб-дизайн) с изображениями и описанием каждой услуги, слайдер отзывов клиентов с оценками, блок статистики с анимированными цифрами и футер с номером телефона. Все блоки плавно появляются при скролле, счётчики в статистике оживают при попадании в зону видимости.
Написано на чистом HTML, CSS и JavaScript, без фреймворков и сборки. Четыре файла: index.html, style.css, index.js, шрифты в папке fonts/, картинки в папке img/. Используются два локальных шрифта: Kucheryavy для заголовков и Montserrat Alternates для основного текста. Внешних API нет — сайт полностью статичный и работает офлайн.
